# Becky's Holiday Apartments Website

## 📖 Project Overview

Becky's Holiday Apartments is a responsive website developed to showcase holiday apartment accommodations in Mombasa, Kenya. The website allows visitors to explore available apartments, view amenities and images, and make booking enquiries through WhatsApp.

---

## 🌟 Features

- Responsive and user-friendly design
- Home page with business information
- Apartments page showcasing:
  - Three-Bedroom Apartment (Nyali)
  - Two-Bedroom Apartment (Buxton – Coming Soon)
- Image gallery for the Nyali apartment
- Booking page
- WhatsApp booking button
- Modern sage green and white theme

---

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or your preferred web browser.
